\section{Analysis contract}

The manuscript is built from the locked Step 13 evidence package. SHA-256
digests bind the claim ledger, result snapshot, artifact manifest, and paper
asset manifest to the build. If any bound input changes, the builder stops
before generating tables or numeric macros. This supplement contains the
pre-specified secondary summaries. It adds no model fitting, participant
exclusions, hyperparameter selection, or confirmatory inference.

The results apply to the analyzed ABIDE-I C-PAC filtered AAL-116 pipeline,
which omits global-signal regression and uses positive-edge graphs with
connectivity-profile node features. Clinical utility, anatomical or causal
connectivity, biological bundle geometry, and BuNN performance outside this
setting were not tested.

\section{Representation endpoints}

Learned-BuNN embeddings may occupy different node-specific frames. Before any
cross-node diagnostic, we mapped them into a common learned frame. The primary
endpoint was normalized effective rank at layer 2, measured against each
operator's matched density-zero anchor. Secondary diagnostics included
dispersion, cosine similarity, invariant edge-transport distance, and the rank
change from encoder to layer 2.

\section{Reproducibility and integrity}

The repository records the participant manifest, technical exclusion rules,
connectome construction, held-out-site splits, operator contracts, tuning
budgets, final seeds, source hashes, run audits, and aggregate result
artifacts. The build reads the locked result snapshot and writes the LaTeX
macros and tables, so manuscript values are not copied by hand. Tests check the
input hashes, deterministic generation, claim coverage, bibliography
resolution, and the absence of manually duplicated primary results in the
