\section*{Data and code availability}
This analysis uses public ABIDE-I derivatives from the Preprocessed
Connectomes Project. The reproducibility package includes the data manifest,
technical exclusions, site splits, configurations, seeds, source hashes,
analysis scripts, and aggregate result artifacts. Participant-linked audit
records are kept separate from the public release package.

\section*{Acknowledgements}
The author thanks the investigators who shared data through ABIDE and the

an NVIDIA A10G cloud instance. AI-assisted tools supported literature
retrieval, code review, debugging, and document preparation. Their use is
documented in the version-controlled provenance log.
