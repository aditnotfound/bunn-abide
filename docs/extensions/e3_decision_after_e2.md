# E3 decision after E2

E3 matched depth/capacity training is **not required for the current completed
paper** and remains deferred.

Study 1 already establishes the result for the frozen two-layer ABIDE-I
architecture. E1 shows that the accepted BuNN map system was active while the
selected topology contributed modestly. E2 now supplies the missing positive
mechanism control: the same transport design succeeds when correct topology and
fixed recoverable frames are both present, fails when either requirement is
broken, and loses its advantage when globally informative features make
propagation unnecessary.

A five-layer matrix would answer a different post-hoc question--whether added
depth, skip connections, or capacity changes ABIDE-I performance--but it would
not be needed to explain the present two-layer result. Running it now would add
many new comparisons and a rescue-study appearance without resolving a gap in
the E1+E2 mechanism argument. E3 should be reconsidered only for a separate
architecture-sensitivity study with its own frozen compute and inference
contract.
